# Дом

Премиальный mobile-first справочник по ремонту и строительству на React.

Главная идея проекта — отвечать на практическую задачу пользователя: быстро найти конкретную работу, понять порядок действий, увидеть инструменты и материалы, типичные ошибки, расчёты и способы исправления.

## Интерфейс

Текущая версия построена вокруг дорогого app-like UX:

- React 19 + Vite;
- cinematic landing с тёмной строительной палитрой и тёплым золотым акцентом;
- desktop workspace проекта ремонта;
- мобильная нижняя навигация;
- каталог разделов и инструкций;
- локальный полнотекстовый поиск и Cmd/Ctrl + K;
- сохранённые инструкции в localStorage;
- интерактивный калькулятор перегородки;
- CSS/React 3D-визуализации проекта и конструкции;
- View Transitions API, scroll reveal, micro-interactions, tilt и magnetic CTA;
- PWA и offline shell;
- поддержка prefers-reduced-motion.

Контент отделён от интерфейса и хранится в `content.js`, поэтому справочник можно расширять без переделки экранов.

## Локальный запуск

```bash
npm install
npm run dev
```

Vite покажет локальный адрес приложения.

## Проверка и сборка

```bash
npm run check
npm run build
npm run preview
```

`npm run build` создаёт готовый каталог `dist/`.

## Развёртывание

Репозиторий: `qtenwten/dom`. Публичный адрес: `https://qsen.ru/dom/`.

- каждый pull request и push в `main` проходит CI;
- Pages workflow повторно проверяет и собирает проект;
- `dist/` публикуется через GitHub Pages;
- приложение не зависит от основного React router сайта qsen;
- Vite собирается с относительной base, а manifest/service worker сохраняют относительный scope, поэтому приложение работает в `/dom/`.

## Контент

Текущие строительные инструкции являются рабочими черновиками. Перед публичным индексированием точные размеры, требования и рекомендации должны быть проверены по действующим нормам, документации производителей и техническим листам.
