# Дом

Мобильный справочник по ремонту и строительству.

Проект ориентирован на практические задачи: найти конкретную работу, быстро понять порядок действий, увидеть инструменты и материалы, типичные ошибки и способы исправления.

## Текущий MVP

- mobile-first интерфейс;
- локальный поиск;
- сохранённые инструкции;
- PWA и offline shell;
- 10 стартовых инструкций по гипсокартону;
- первый черновой калькулятор перегородки;
- архитектура для дальнейшего расширения.

## Локальный запуск

```bash
npm install
python3 -m http.server 4173
```

Затем откройте `http://localhost:4173/`.

Не открывайте `index.html` напрямую через `file://`: service worker и часть PWA-функций требуют HTTP/HTTPS.

## Проверка и сборка

```bash
npm run check
npm run build
```

`npm run build` создаёт готовый статический каталог `dist/`.

## Развёртывание

Репозиторий: `qtenwten/dom`. Публичный адрес: `https://qsen.ru/dom/`.

Схема такая же по принципу, как у `eng-source`:

- каждый push в `main` запускает отдельный CI;
- отдельный Pages workflow проверяет и собирает проект;
- `dist/` загружается как GitHub Pages artifact;
- `actions/deploy-pages` публикует приложение;
- основной `qsen-source` в публикации Dom не участвует.

Manifest и service worker используют относительную базу, поэтому приложение переносимо между корнем сайта и подкаталогом.

## Контент

Текущие строительные инструкции являются рабочими черновиками. Перед публичным индексированием точные размеры, требования и рекомендации должны быть проверены по действующим нормам, документации производителей и техническим листам.
